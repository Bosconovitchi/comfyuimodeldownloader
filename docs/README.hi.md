# ComfyUI-Model-Downloader

**ComfyUI टेम्पलेट्स और वर्कफ़्लो के लिए गायब मॉडलों का वन-क्लिक, फुल-स्पीड डाउनलोड — क्यू प्रबंधन, प्रति-फ़ाइल क्रियाओं और अखंडता सत्यापन के साथ।**

एक शुद्ध ComfyUI प्लगइन। कोई स्टैंडअलोन सर्वर नहीं, कोई अतिरिक्त डेमॉन नहीं: बैकएंड ComfyUI सर्वर प्रक्रिया के अंदर रहता है और UI ComfyUI पेज के अंदर रहता है। ComfyUI बंद करें और सब कुछ रुक जाता है (डाउनलोड सहित, `aria2c --stop-with-process` के ज़रिए)।

## यह प्लगइन क्यों मौजूद है

ComfyUI का बिल्ट-इन टेम्पलेट डाउनलोडर मॉडलों को **सिंगल-थ्रेडेड** डाउनलोड करता है, और कुछ क्षेत्रों में `huggingface.co` अप्राप्य या बुरी तरह थ्रॉटल होता है, इसलिए बिल्ट-इन "Download" बटन विफल हो जाता है या रेंगता है। यह प्लगइन:

- वर्तमान में खुले टेम्पलेट/वर्कफ़्लो के लिए **कौन से मॉडल गायब हैं** यह पता लगाता है (वही मेटाडेटा जो बिल्ट-इन मिसिंग-मॉडल्स पैनल उपयोग करता है)।
- उन्हें **aria2c, प्रति फ़ाइल 16 कनेक्शन, समानांतर में 3 फ़ाइलें** के साथ **hf-mirror.com** के ज़रिए स्वचालित रूप से डाउनलोड करता है (एक तेज़ Hugging Face मिरर) — आमतौर पर आपकी बैंडविड्थ को संतृप्त करता है।
- बाधित डाउनलोड फिर से शुरू करता है, **फ़ाइल अखंडता सत्यापित करता है** (Hugging Face के आधिकारिक LFS रिकॉर्ड के विरुद्ध आकार + SHA256), और आपको एक पूर्ण **डाउनलोड मैनेजर पैनल** देता है: रीट्राई, कैंसल, सभी रोकें, क्यू पुनर्व्यवस्थित करें, फ़ाइल हटाएँ, फ़ोल्डर में दिखाएँ।

## यह कैसे काम करता है

```
┌──────────────────────── ComfyUI ────────────────────────┐
│  Frontend (web/index.js)                                │
│  • scans the graph every 2s for node properties.models  │
│  • floating button: "⬇ Download N missing models"       │
│  • download manager panel (progress/speed/actions)      │
│          │ REST (same-origin)                           │
│  Backend (__init__.py, in-process routes)               │
│  • /comfy_fetch/check   – existence + integrity check   │
│  • /comfy_fetch/download– queue, aria2c ×16, 3 parallel │
│  • retry/cancel/stop/reorder/delete/reveal              │
└─────────────────────────────────────────────────────────┘
```

- **जीवनचक्र बंधन**: सब कुछ ComfyUI के अंदर चलता है। ComfyUI रोकें → रूट गायब हो जाते हैं और हर चालू `aria2c` खुद को समाप्त कर लेता है (`--stop-with-process=<सर्वर pid>`)। फ्रंटएंड पेज छिपे होने पर पोलिंग भी रोक देता है और अनलोड होने पर सफाई करता है।
- **डाउनलोड केवल मैन्युअल हैं**: टेम्पलेट बदलने से केवल गायब-मॉडल की गिनती ताज़ा होती है। जब तक आप बटन क्लिक नहीं करते तब तक कुछ भी डाउनलोड नहीं होता (या डाउनलोड चलते समय फिर से बटन क्लिक करते हैं, ताकि नए टेम्पलेट के गायब मॉडल क्यू में जुड़ जाएँ)।

## विशेषताएँ

| विशेषता | विवरण |
|---|---|
| स्वचालित पहचान | टेम्पलेट खोलें → फ़्लोटिंग बटन दिखाता है कि कितने मॉडल गायब हैं। टेम्पलेट बदलें → गिनती स्वतः अपडेट होती है। |
| तेज़ डाउनलोड | aria2c, 16 कनेक्शन/फ़ाइल, 3 समानांतर फ़ाइलें, Hugging Face URL के लिए स्वचालित `hf-mirror.com` मिरर। |
| क्यू प्रबंधन | डाउनलोड के बीच और मॉडल क्यू करें, आइटम ऊपर/नीचे करें, अलग-अलग आइटम कैंसल करें, सब कुछ रोकें। |
| अखंडता सत्यापन | हर जाँच पर: गायब फ़ाइल, बची हुई `.aria2` (अधूरी → ऑटो-रीज़्यूम), आकार बेमेल, SHA256 बेमेल (HF LFS रिकॉर्ड के विरुद्ध)। हर डाउनलोड के बाद: SHA256 पुनः-सत्यापन। सत्यापित फ़ाइलें प्रति सत्र कैश होती हैं (mtime+आकार) ताकि हर टेम्पलेट बदलाव पर बड़ी फ़ाइलें दोबारा हैश न हों। |
| प्रति-फ़ाइल क्रियाएँ | रीट्राई, कैंसल, ⏫/⏬ पुनर्व्यवस्था, डिस्क से फ़ाइल हटाएँ (पुष्टि के साथ), Windows Explorer में दिखाएँ। |
| रीज़्यूम | बाधित डाउनलोड अपनी `.aria2` नियंत्रण फ़ाइल रखते हैं; दोबारा डाउनलोड क्लिक करने पर फिर से शुरू करने के बजाय रीज़्यूम होता है। |

## आवश्यकताएँ

- **ComfyUI** (कस्टम-नोड समर्थन वाला कोई भी हालिया संस्करण; ComfyUI 0.3.x + Comfy Desktop 1.x पर परीक्षित)
- **aria2c** उस वातावरण के `PATH` पर जो ComfyUI शुरू करता है
- `requests` Python पैकेज (मानक ComfyUI इंस्टॉल में पहले से मौजूद)
- Windows / Linux समर्थित ("फ़ोल्डर में दिखाएँ" बटन केवल Windows के लिए है; Linux सहजता से फ़ॉलबैक करता है)

### aria2 इंस्टॉल करना

- **Windows**: <https://github.com/aria2/aria2/releases> से ZIP डाउनलोड करें (जैसे `aria2-1.37.0-win-64bit-build1.zip`), निकालें, और `aria2c.exe` वाले फ़ोल्डर को अपने उपयोगकर्ता `PATH` में जोड़ें।
- **Linux**: `sudo apt install aria2` / `sudo dnf install aria2` / `brew install aria2` (macOS)।
- सत्यापित करें: टर्मिनल खोलें और `aria2c --version` चलाएँ।

## इंस्टॉलेशन

### विधि 1 — ComfyUI Manager

1. ComfyUI खोलें → **Manager** → **Custom Nodes Manager**।
2. `ComfyUI-Model-Downloader` खोजें और इंस्टॉल करें।
3. ComfyUI पुनः आरंभ करें।

### विधि 2 — git clone

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Bosconovitchi/comfyuimodeldownloader.git ComfyUI-Model-Downloader
# restart ComfyUI
```

> **डेस्कटॉप ऐप (Comfy Desktop)**: `custom_nodes` फ़ोल्डर इंस्टॉलेशन के अंदर है, जैसे `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs\<instance>\ComfyUI\custom_nodes` (पथ लेआउट के अनुसार भिन्न होता है)। संदेह होने पर सर्वर लॉग का "Import times for custom nodes" अनुभाग देखें कि वास्तव में कौन सी निर्देशिका स्कैन होती है।

## उपयोग

1. इंस्टॉलेशन के बाद **ComfyUI पुनः आरंभ करें** (यदि सर्वर ने प्लगइन दोबारा लोड नहीं किया तो उसका कोई UI नहीं होता)।
2. कोई भी **टेम्पलेट** खोलें (या कोई भी वर्कफ़्लो जिसके नोड्स `properties.models` मेटाडेटा समाहित करते हैं — आधिकारिक टेम्पलेट ऐसा करते हैं)।
3. ~2 सेकंड प्रतीक्षा करें। **नीचे-दाईं ओर** एक फ़्लोटिंग बटन दिखाई देता है:
   - `⬇ Download missing models (N)` — N मॉडल गायब/खराब हैं। डाउनलोड शुरू करने के लिए **इसे क्लिक करें**।
4. **डाउनलोड मैनेजर पैनल** स्वचालित रूप से खुलता है और हर फ़ाइल दिखाता है: स्टेटस आइकन, प्रगति पट्टी, प्रतिशत, लाइव गति, लक्ष्य फ़ोल्डर, त्रुटि संदेश।
5. डाउनलोड के दौरान आप यह कर सकते हैं:
   - टेम्पलेट बदलें → बटन दिखाता है `Downloading x/y · Pending N (click to enqueue)`। **कुछ भी स्वतः डाउनलोड नहीं होता**; नए टेम्पलेट के गायब मॉडलों को क्यू में जोड़ने के लिए बटन क्लिक करें।
   - पैनल में: क्यू किए गए आइटम ⏫/⏬ पुनर्व्यवस्थित करें, एक आइटम **कैंसल** करें, **सभी रोकें**, विफल आइटम **रीट्राई** करें, **फ़ाइल हटाएँ**, **फ़ोल्डर में दिखाएँ**।
6. जब सब कुछ पूरा हो जाता है, पैनल अंतिम परिणाम (✅/⚠️) रखता है जब तक आप उसे ✕ से बंद नहीं करते।

### बटन क्या दिखाता है

| स्थिति | बटन टेक्स्ट | क्लिक क्रिया |
|---|---|---|
| कोई डाउनलोड नहीं चल रहा, मॉडल गायब | `⬇ Download missing models (N)` | डाउनलोड शुरू करें |
| डाउनलोड चल रहा, कोई नई कमी नहीं | `Downloading x/y · file 45%` | पैनल खोलें |
| डाउनलोड चल रहा, नए टेम्पलेट के मॉडल गायब | `Downloading x/y · Pending N (click to enqueue)` | उन्हें क्यू करें |
| सब समाप्त, कुछ विफल | `⚠ x ok / y failed (click to retry)` | विफलताएँ रीट्राई करें |
| कुछ गायब नहीं | (छिपा हुआ) | — |

## डाउनलोड तर्क और अखंडता

हर मॉडल के लिए प्लगइन (क्रम से) जाँच करता है:

1. फ़ाइल अनुपस्थित या ≤ 1 MB → **गायब** → डाउनलोड करें।
2. `<file>.aria2` मौजूद है → **अधूरा** → aria2c इसे रीज़्यूम करता है।
3. आकार ≠ Hugging Face LFS रिकॉर्ड → **भ्रष्ट** → हटाएँ और दोबारा डाउनलोड करें।
4. SHA256 ≠ Hugging Face LFS रिकॉर्ड → **भ्रष्ट** → हटाएँ और दोबारा डाउनलोड करें (प्रति सत्र प्रति फ़ाइल केवल एक बार सत्यापित, जब तक फ़ाइल बदलती नहीं)।
5. हर पूर्ण डाउनलोड के बाद SHA256 फिर से जाँचा जाता है; बेमेल होने पर आइटम विफल चिह्नित होता है।

अपेक्षित आकार/हैश `https://hf-mirror.com/api/models/{owner}/{repo}/tree/{rev}?recursive=true` से आते हैं और प्रति URL कैश होते हैं। गैर-Hugging-Face URL (जैसे Civitai) केवल अस्तित्व + `.aria2` + आकार जाँच पर आते हैं।

## प्रतिबंधित रिपॉज़िटरी (लाइसेंस-आवश्यक मॉडल)

कुछ मॉडल (जैसे LTX-2.5, Gemma) Hugging Face पर **gated** (प्रतिबंधित) हैं — डाउनलोड करने से पहले आपको लाइसेंस स्वीकार करना / एक्सेस का अनुरोध करना होगा। प्लगइन इसे पहचान लेता है और रहस्यमय त्रुटि के बजाय स्पष्ट संदेश के साथ विफल होता है।

1. huggingface.co पर मॉडल पेज खोलें (जैसे https://huggingface.co/Lightricks/LTX-2.5), साइन इन करें, और शर्तें स्वीकार करें / एक्सेस का अनुरोध करें।
2. एक रीड-ओनली एक्सेस टोकन बनाएँ: https://huggingface.co/settings/tokens → New token → प्रकार **Read**।
3. इसे ComfyUI के लिए एनवायरनमेंट वेरिएबल के रूप में सेट करें और पुनः आरंभ करें:
   - Windows (PowerShell): `setx HF_TOKEN hf_xxxxxxxx`
   - Linux/macOS: `export HF_TOKEN=hf_xxxxxxxx` (अपनी ComfyUI स्टार्ट स्क्रिप्ट में जोड़ें)
4. ComfyUI पुनः आरंभ करें और दोबारा कोशिश करें — अब डाउनलोड `Authorization: Bearer <token>` साथ ले जाते हैं, और अखंडता मेटाडेटा (आकार/SHA256) भी टोकन के साथ ही प्राप्त किया जाता है।

## कॉन्फ़िगरेशन

सभी समायोज्य `__init__.py` के शीर्ष पर स्थिरांक हैं:

| स्थिरांक | डिफ़ॉल्ट | अर्थ |
|---|---|---|
| `MAX_CONCURRENT` | `3` | समानांतर फ़ाइलें |
| aria2 फ़्लैग | `-x16 -s16 -k1M` | 16 कनेक्शन/फ़ाइल, 1 MB चंक |
| `HF_MIRROR` | `https://hf-mirror.com` | `huggingface.co` URL के लिए उपयोग किया गया मिरर |
| `MIN_FILE_SIZE` | `1_000_000` | इससे छोटी फ़ाइलें गायब गिनी जाती हैं |
| `ARIA2_FALLBACKS` | स्थानीय पथ | यदि PATH पर नहीं है तो आज़माए जाने वाले पूर्ण aria2c स्थान |

| लक्षण | समाधान |

| टेम्पलेट खोलने के बाद बटन कुछ नहीं दिखाता | वर्कफ़्लो के नोड्स में `properties.models` मेटाडेटा समाहित होना चाहिए (आधिकारिक टेम्पलेट में होता है)। बिना मेटाडेटा वाले हस्तनिर्मित वर्कफ़्लो के लिए प्लगइन के पास जाँचने को कुछ नहीं है — मॉडल मैन्युअल रूप से जोड़ें। |
| डाउनलोड तुरंत विफल हो जाता है | `aria2c` नहीं मिला → aria2 इंस्टॉल करें और सुनिश्चित करें कि वह उस PATH पर है जिससे ComfyUI शुरू होता है (पुनः आरंभ आवश्यक)। |
| बहुत धीमा | आपका नेटवर्क `hf-mirror.com` तक भी नहीं पहुँच पाता; प्रॉक्सी आज़माएँ। |
| टेम्पलेट बदलने के बाद गिनती पुरानी लगती है | पोल चक्र के लिए ~2 सेकंड प्रतीक्षा करें; बनी रहे तो हार्ड-रिफ्रेश (Ctrl+R) करें। |
| पैनल क्रिया कुछ नहीं करती | फ़ाइल शायद पहले ही हट चुकी है (डिलीट) या क्यू में नहीं है (पुनर्व्यवस्था); पैनल के स्टेटस आइकन जाँचें। |

## API संदर्भ (डेवलपर्स के लिए)

सभी एंडपॉइंट ComfyUI सर्वर द्वारा ही परोसे जाते हैं (कोई अतिरिक्त पोर्ट नहीं):

```
GET  /comfy_fetch/ping                       → {"ok": true}
GET  /comfy_fetch/status                     → {"running", "items", "queue"}
POST /comfy_fetch/check   {models:[...]}     → {"missing":[{url,name,directory,reason}]}
POST /comfy_fetch/download {models:[...]}    → {"started":true,"count":N}  (idempotent-ish, dedupes)
POST /comfy_fetch/retry  {name,directory}    → re-queue a failed/cancelled item
POST /comfy_fetch/cancel {name,directory}    → cancel one item (kills its aria2c)
POST /comfy_fetch/stop   {}                  → stop everything
POST /comfy_fetch/reorder {name,directory,direction:"up"|"down"}
POST /comfy_fetch/delete {name,directory}    → delete the model file from disk
POST /comfy_fetch/reveal {name,directory}    → open Explorer at the file (Windows)
```

गायब आइटम पर `reason`: `missing` | `incomplete` (ऑटो-रीज़्यूम) | `size` | `hash`।
