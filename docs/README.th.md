# ComfyUI-Model-Downloader

**ดาวน์โหลดโมเดลที่ขาดหายไปสำหรับเทมเพลตและเวิร์กโฟลว์ของ ComfyUI ด้วยคลิกเดียวเต็มความเร็ว — พร้อมการจัดการคิว การทำงานรายไฟล์ และการตรวจสอบความสมบูรณ์ของไฟล์**

ปลั๊กอินล้วนของ ComfyUI ไม่มีเซิร์ฟเวอร์แยก ไม่มีเดมอนเพิ่มเติม: แบ็กเอนด์ทำงานอยู่ในกระบวนการเซิร์ฟเวอร์ของ ComfyUI และ UI ทำงานอยู่ในหน้าเว็บของ ComfyUI ปิด ComfyUI แล้วทุกอย่างจะหยุดทำงาน (รวมถึงการดาวน์โหลด ผ่าน `aria2c --stop-with-process`)

## ทำไมถึงมีปลั๊กอินนี้

ตัวดาวน์โหลดเทมเพลตในตัวของ ComfyUI ดาวน์โหลดโมเดลแบบ**เธรดเดียว** และในบางภูมิภาค `huggingface.co` เข้าถึงไม่ได้หรือถูกจำกัดความเร็วอย่างหนัก ทำให้ปุ่ม "Download" ในตัวล้มเหลวหรือช้าแบบคลาน ปลั๊กอินนี้จะ:

- ตรวจพบ**โมเดลใดที่ขาดหายไป**สำหรับเทมเพลต/เวิร์กโฟลว์ที่เปิดอยู่ (ใช้เมทาดาทาชุดเดียวกับแผงโมเดลที่ขาดหายในตัว)
- ดาวน์โหลดโมเดลเหล่านั้นด้วย **aria2c, 16 การเชื่อมต่อต่อไฟล์, 3 ไฟล์พร้อมกัน** ผ่าน **hf-mirror.com** โดยอัตโนมัติ (มิเรอร์ Hugging Face ที่เร็ว) — โดยปกติแล้วจะใช้แบนด์วิดท์ของคุณจนเต็ม
- ดาวน์โหลดต่อจากการดาวน์โหลดที่ถูกขัดจังหวะ **ตรวจสอบความสมบูรณ์ของไฟล์** (ขนาด + SHA256 เทียบกับบันทึก LFS อย่างเป็นทางการของ Hugging Face) และมอบ**แผงตัวจัดการดาวน์โหลด**ครบชุด: ลองใหม่ ยกเลิก หยุดทั้งหมด เรียงลำดับคิวใหม่ ลบไฟล์ เปิดโฟลเดอร์

## วิธีการทำงาน

```
┌──────────────────────── ComfyUI ────────────────────────┐
│  Frontend (web/index.js)                                │
│  • scans the graph every 2s for node properties.models  │
│  • floating button: "⬇ Download N missing models"       │
│  • download manager panel (progress/speed/actions)      │
│          │ REST (same-origin)                           │
│  Backend (__init__.py, in-process routes)               │
│  • /comfy_fetch/check   – existence + integrity check   │
│  • /comfy_fetch/download– queue, aria2c ×16, 3 parallel │
│  • retry/cancel/stop/reorder/delete/reveal              │
└─────────────────────────────────────────────────────────┘
```

- **ผูกกับวงจรชีวิต**: ทุกอย่างทำงานภายใน ComfyUI หยุด ComfyUI → เส้นทาง (route) หายไป และทุก `aria2c` ที่กำลังทำงานจะยุติตัวเอง (`--stop-with-process=<server pid>`) ฝั่งฟรอนต์เอนด์ยังหยุดการโพลชั่วคราวระหว่างที่หน้าเว็บถูกซ่อน และล้างข้อมูลเมื่อปิดหน้า (unload)
- **ดาวน์โหลดแบบใช้มือเท่านั้น**: การสลับเทมเพลตเพียงแค่รีเฟรชจำนวนโมเดลที่ขาดหาย ยังไม่มีการดาวน์โหลดอะไรจนกว่าคุณจะคลิกปุ่ม (หรือคลิกปุ่มอีกครั้งระหว่างที่กำลังดาวน์โหลด เพื่อนำโมเดลที่ขาดของเทมเพลตใหม่เข้าคิว)

## คุณสมบัติ

| คุณสมบัติ | คำอธิบาย |
|---|---|
| ตรวจจับอัตโนมัติ | เปิดเทมเพลต → ปุ่มลอยจะแสดงจำนวนโมเดลที่ขาดหาย สลับเทมเพลต → จำนวนจะอัปเดตอัตโนมัติ |
| ดาวน์โหลดเร็ว | aria2c, 16 การเชื่อมต่อ/ไฟล์, 3 ไฟล์พร้อมกัน, ใช้มิเรอร์ `hf-mirror.com` อัตโนมัติสำหรับ URL ของ Hugging Face |
| จัดการคิว | เพิ่มโมเดลเพิ่มระหว่างดาวน์โหลด ย้ายรายการขึ้น/ลง ยกเลิกทีละรายการ หยุดทั้งหมด |
| ตรวจสอบความสมบูรณ์ | ทุกครั้งที่ตรวจ: ไฟล์หาย เหลือไฟล์ `.aria2` (ยังไม่สมบูรณ์ → ดาวน์โหลดต่ออัตโนมัติ) ขนาดไม่ตรง SHA256 ไม่ตรง (เทียบกับบันทึก LFS ของ HF) หลังดาวน์โหลดแต่ละไฟล์: ตรวจ SHA256 ซ้ำ ไฟล์ที่ตรวจแล้วจะถูกแคชต่อเซสชัน (mtime+ขนาด) จึงไม่ต้องแฮชไฟล์ใหญ่ใหม่ทุกครั้งที่สลับเทมเพลต |
| การทำงานรายไฟล์ | ลองใหม่ ยกเลิก เรียงลำดับ ⏫/⏬ ลบไฟล์ออกจากดิสก์ (ต้องยืนยัน) เปิดใน Windows Explorer |
| ดาวน์โหลดต่อ | การดาวน์โหลดที่ถูกขัดจังหวะเก็บไฟล์ควบคุม `.aria2` ไว้ การคลิกดาวน์โหลดอีกครั้งจะดาวน์โหลดต่อแทนที่จะเริ่มใหม่ |

## ข้อกำหนด

- **ComfyUI** (เวอร์ชันใหม่ที่รองรับ custom node; ทดสอบบน ComfyUI 0.3.x + Comfy Desktop 1.x)
- **aria2c** อยู่ใน `PATH` ของสภาพแวดล้อมที่ใช้เริ่ม ComfyUI
- แพ็กเกจ Python `requests` (มีอยู่แล้วในการติดตั้ง ComfyUI มาตรฐาน)
- รองรับ Windows / Linux (ปุ่ม "เปิดโฟลเดอร์" มีเฉพาะ Windows; Linux จะใช้ทางเลือกอื่นโดยอัตโนมัติ)

### การติดตั้ง aria2

- **Windows**: ดาวน์โหลด ZIP จาก <https://github.com/aria2/aria2/releases> (เช่น `aria2-1.37.0-win-64bit-build1.zip`) แตกไฟล์ แล้วเพิ่มโฟลเดอร์ที่มี `aria2c.exe` ลงใน `PATH` ของผู้ใช้
- **Linux**: `sudo apt install aria2` / `sudo dnf install aria2` / `brew install aria2` (macOS)
- ตรวจสอบ: เปิดเทอร์มินัลแล้วรัน `aria2c --version`

## การติดตั้ง

### วิธีที่ 1 — ComfyUI Manager

1. เปิด ComfyUI → **Manager** → **Custom Nodes Manager**
2. ค้นหา `ComfyUI-Model-Downloader` แล้วติดตั้ง
3. รีสตาร์ต ComfyUI

### วิธีที่ 2 — git clone

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Bosconovitchi/comfyuimodeldownloader.git ComfyUI-Model-Downloader
# restart ComfyUI
```

> **แอปเดสก์ท็อป (Comfy Desktop)**: โฟลเดอร์ `custom_nodes` อยู่ภายในโฟลเดอร์ติดตั้ง เช่น `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs\<instance>\ComfyUI\custom_nodes` (เส้นทางต่างกันตามเลย์เอาต์) หากไม่แน่ใจ ให้ดูส่วน "Import times for custom nodes" ในล็อกของเซิร์ฟเวอร์เพื่อดูว่าไดเรกทอรีใดถูกสแกนจริง

## การใช้งาน

1. **รีสตาร์ต ComfyUI** หลังติดตั้ง (หากเซิร์ฟเวอร์ยังไม่โหลดใหม่ ปลั๊กอินจะไม่มี UI)
2. เปิด**เทมเพลต**ใดก็ได้ (หรือเวิร์กโฟลว์ที่โหนดฝังเมทาดาทา `properties.models` — เทมเพลตทางการทำเช่นนั้น)
3. รอประมาณ 2 วินาที ปุ่มลอยจะปรากฏที่**มุมล่างขวา**:
   - `⬇ Download missing models (N)` — มี N โมเดลที่ขาดหาย/เสียหาย **คลิกปุ่ม**เพื่อเริ่มดาวน์โหลด
4. **แผงตัวจัดการดาวน์โหลด**จะเปิดโดยอัตโนมัติ แสดงทุกไฟล์: ไอคอนสถานะ แถบความคืบหน้า เปอร์เซ็นต์ ความเร็วแบบเรียลไทม์ โฟลเดอร์เป้าหมาย ข้อความแสดงข้อผิดพลาด
5. ระหว่างดาวน์โหลด คุณสามารถ:
   - สลับเทมเพลต → ปุ่มจะแสดง `Downloading x/y · Pending N (click to enqueue)` **ไม่มีอะไรดาวน์โหลดอัตโนมัติ** คลิกปุ่มเพื่อเพิ่มโมเดลที่ขาดของเทมเพลตใหม่เข้าคิว
   - ในแผง: เรียงลำดับรายการที่เข้าคิวด้วย ⏫/⏬ **ยกเลิก**ทีละรายการ **หยุดทั้งหมด** **ลองใหม่**รายการที่ล้มเหลว **ลบไฟล์** **เปิดโฟลเดอร์**
6. เมื่อทุกอย่างเสร็จ แผงจะเก็บผลลัพธ์สุดท้ายไว้ (✅/⚠️) จนกว่าคุณจะปิดด้วย ✕

## ตรรกะการดาวน์โหลดและความสมบูรณ์

สำหรับแต่ละโมเดล ปลั๊กอินจะตรวจ (ตามลำดับ):

1. ไม่มีไฟล์หรือ ≤ 1 MB → **ขาดหาย** → ดาวน์โหลด
2. มี `<file>.aria2` → **ยังไม่สมบูรณ์** → aria2c ดาวน์โหลดต่อ
3. ขนาด ≠ บันทึก LFS ของ Hugging Face → **เสียหาย** → ลบแล้วดาวน์โหลดใหม่
4. SHA256 ≠ บันทึก LFS ของ Hugging Face → **เสียหาย** → ลบแล้วดาวน์โหลดใหม่ (ตรวจเพียงครั้งเดียวต่อเซสชันต่อไฟล์ เว้นแต่ไฟล์มีการเปลี่ยนแปลง)
5. หลังดาวน์โหลดเสร็จทุกครั้ง จะตรวจ SHA256 ซ้ำ หากไม่ตรงจะทำเครื่องหมายรายการนั้นว่าล้มเหลว

ขนาด/แฮชที่คาดหวังมาจาก `https://hf-mirror.com/api/models/{owner}/{repo}/tree/{rev}?recursive=true` และถูกแคชต่อ URL URL ที่ไม่ใช่ Hugging Face (เช่น Civitai) จะใช้เฉพาะการตรวจว่ามีไฟล์อยู่ + `.aria2` + ขนาด

## โพสิทอรีที่จำกัดสิทธิ์ (โมเดลที่ต้องยอมรับใบอนุญาต)

บางโมเดล (เช่น LTX-2.5, Gemma) ถูก**จำกัดสิทธิ์ (gated)** บน Hugging Face — คุณต้องยอมรับใบอนุญาต / ขอสิทธิ์เข้าถึงก่อนจึงจะดาวน์โหลดได้ ปลั๊กอินจะตรวจพบกรณีนี้และแจ้งข้อผิดพลาดด้วยข้อความที่ชัดเจนแทนที่จะเป็นข้อผิดพลาดที่อ่านไม่ออก

1. เปิดหน้าโมเดลบน huggingface.co (เช่น https://huggingface.co/Lightricks/LTX-2.5) ลงชื่อเข้าใช้ แล้วยอมรับข้อตกลง / ขอสิทธิ์เข้าถึง
2. สร้างโทเค็นการเข้าถึงแบบอ่านอย่างเดียว: https://huggingface.co/settings/tokens → New token → ประเภท **Read**
3. ตั้งเป็นตัวแปรสภาพแวดล้อมสำหรับ ComfyUI แล้วรีสตาร์ต:
   - Windows (PowerShell): `setx HF_TOKEN hf_xxxxxxxx`
   - Linux/macOS: `export HF_TOKEN=hf_xxxxxxxx` (เพิ่มลงในสคริปต์เริ่มต้น ComfyUI)
4. รีสตาร์ต ComfyUI แล้วลองใหม่ — การดาวน์โหลดจะแนบ `Authorization: Bearer <token>` ไปด้วย และเมทาดาทาความสมบูรณ์ (ขนาด/SHA256) ก็ถูกดึงด้วยโทเค็นเช่นกัน

## การกำหนดค่า

ค่าที่ปรับได้ทั้งหมดเป็นค่าคงที่ที่ด้านบนของ `__init__.py`:

| ค่าคงที่ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `MAX_CONCURRENT` | `3` | จำนวนไฟล์ที่ดาวน์โหลดพร้อมกัน |
| แฟล็ก aria2 | `-x16 -s16 -k1M` | 16 การเชื่อมต่อ/ไฟล์, ชิ้นส่วน 1 MB |
| `HF_MIRROR` | `https://hf-mirror.com` | มิเรอร์ที่ใช้สำหรับ URL ของ `huggingface.co` |
| `MIN_FILE_SIZE` | `1_000_000` | ไฟล์ที่เล็กกว่านี้ถือว่าขาดหาย |
| `ARIA2_FALLBACKS` | พาธในเครื่อง | ตำแหน่ง aria2c แบบสัมบูรณ์ที่จะลองใช้หากไม่อยู่ใน PATH |

## การแก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีปุ่มลอยเลย | รีสตาร์ต ComfyUI ให้สมบูรณ์ (เดสก์ท็อป: ถาดระบบ → ออก) ตรวจล็อกของเซิร์ฟเวอร์ว่ามี `Import times for custom nodes: … ComfyUI-Model-Downloader` ในหน้าเว็บให้รีเฟรชแบบฮาร์ด (Ctrl+R) เช็กสุขภาพ: เปิด `http://127.0.0.1:8188/comfy_fetch/ping` → ควรคืนค่า `{"ok": true}` |
| เปิดเทมเพลตแล้วปุ่มไม่แสดงอะไร | โหนดของเวิร์กโฟลว์ต้องฝังเมทาดาทา `properties.models` (เทมเพลตทางการมี) สำหรับเวิร์กโฟลว์ที่ทำเองโดยไม่มีเมทาดาทา ปลั๊กอินไม่มีอะไรให้ตรวจ — เพิ่มโมเดลด้วยตนเอง |
| ดาวน์โหลดล้มเหลวทันที | หา `aria2c` ไม่พบ → ติดตั้ง aria2 และตรวจสอบว่าอยู่ใน PATH ที่ใช้เริ่ม ComfyUI (ต้องรีสตาร์ต) |
| ช้ามาก | เครือข่ายของคุณเข้า `hf-mirror.com` ไม่ได้เช่นกัน ลองใช้พร็อกซี |
| จำนวนดูเก่าไปหลังสลับเทมเพลต | รอประมาณ 2 วินาทีให้ครบรอบการโพล หากยังเป็นอยู่ให้รีเฟรชแบบฮาร์ด (Ctrl+R) |
| การทำงานในแผงไม่มีผลอะไร | ไฟล์อาจถูกลบไปแล้ว (ลบ) หรือไม่อยู่ในคิว (เรียงลำดับ) ตรวจไอคอนสถานะในแผง |

## เอกสารอ้างอิง API (สำหรับนักพัฒนา)

ทุกเอนด์พอยต์ให้บริการโดยเซิร์ฟเวอร์ ComfyUI เอง (ไม่ต้องใช้พอร์ตเพิ่ม):

```
GET  /comfy_fetch/ping                       → {"ok": true}
GET  /comfy_fetch/status                     → {"running", "items", "queue"}
POST /comfy_fetch/check   {models:[...]}     → {"missing":[{url,name,directory,reason}]}
POST /comfy_fetch/download {models:[...]}    → {"started":true,"count":N}  (idempotent-ish, dedupes)
POST /comfy_fetch/retry  {name,directory}    → re-queue a failed/cancelled item
POST /comfy_fetch/cancel {name,directory}    → cancel one item (kills its aria2c)
POST /comfy_fetch/stop   {}                  → stop everything
POST /comfy_fetch/reorder {name,directory,direction:"up"|"down"}
POST /comfy_fetch/delete {name,directory}    → delete the model file from disk
POST /comfy_fetch/reveal {name,directory}    → open Explorer at the file (Windows)
```

`reason` ของรายการที่ขาดหาย: `missing` | `incomplete` (ดาวน์โหลดต่ออัตโนมัติ) | `size` | `hash`
