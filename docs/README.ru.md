# ComfyUI-Model-Downloader

**Скачивание отсутствующих моделей для шаблонов и рабочих процессов ComfyUI в один клик и на полной скорости — с управлением очередью, действиями для каждого файла и проверкой целостности.**

Чистый плагин для ComfyUI. Без отдельного сервера и лишних демонов: бэкенд живёт внутри процесса сервера ComfyUI, а интерфейс — внутри страницы ComfyUI. Закройте ComfyUI — и всё остановится (включая загрузки, благодаря `aria2c --stop-with-process`).

## Зачем нужен этот плагин

Встроенный загрузчик шаблонов ComfyUI качает модели **в один поток**, а в некоторых регионах `huggingface.co` недоступен или сильно ограничен по скорости, поэтому встроенная кнопка "Download" не работает или еле ползёт. Этот плагин:

- Определяет, **какие модели отсутствуют** для текущего открытого шаблона/рабочего процесса (те же метаданные, что использует встроенная панель отсутствующих моделей).
- Скачивает их с помощью **aria2c: 16 соединений на файл, 3 файла параллельно**, автоматически через **hf-mirror.com** (быстрое зеркало Hugging Face) — обычно полностью загружая ваш канал.
- Докачивает прерванные загрузки, **проверяет целостность файлов** (размер + SHA256 по официальным LFS-записям Hugging Face) и даёт полноценную **панель менеджера загрузок**: повтор, отмена, остановить всё, перестановка очереди, удаление файла, показать в папке.

## Как это работает

```
┌──────────────────────── ComfyUI ────────────────────────┐
│  Frontend (web/index.js)                                │
│  • scans the graph every 2s for node properties.models  │
│  • floating button: "⬇ Download N missing models"       │
│  • download manager panel (progress/speed/actions)      │
│          │ REST (same-origin)                           │
│  Backend (__init__.py, in-process routes)               │
│  • /comfy_fetch/check   – existence + integrity check   │
│  • /comfy_fetch/download– queue, aria2c ×16, 3 parallel │
│  • retry/cancel/stop/reorder/delete/reveal              │
└─────────────────────────────────────────────────────────┘
```

- **Привязка к жизненному циклу**: всё работает внутри ComfyUI. Остановите ComfyUI → маршруты исчезают, и каждый запущенный `aria2c` завершается сам (`--stop-with-process=<server pid>`). Фронтенд также приостанавливает опрос, пока страница скрыта, и очищает ресурсы при её закрытии.
- **Загрузки только вручную**: переключение шаблонов лишь обновляет счётчик отсутствующих моделей. Ничего не скачивается, пока вы не нажмёте кнопку (или не нажмёте её ещё раз во время загрузки, чтобы добавить в очередь отсутствующие модели нового шаблона).

## Возможности

| Возможность | Описание |
|---|---|
| Автоопределение | Откройте шаблон → плавающая кнопка показывает, сколько моделей отсутствует. Переключите шаблон → счётчик обновится автоматически. |
| Быстрые загрузки | aria2c, 16 соединений на файл, 3 параллельных файла, автоматическое зеркало `hf-mirror.com` для URL Hugging Face. |
| Управление очередью | Добавляйте модели в очередь во время загрузки, перемещайте элементы вверх/вниз, отменяйте отдельные элементы, останавливайте всё. |
| Проверка целостности | При каждой проверке: отсутствующий файл, остаточный `.aria2` (незавершённый → автодокачка), несовпадение размера, несовпадение SHA256 (с записями LFS Hugging Face). После каждой загрузки: повторная проверка SHA256. Проверенные файлы кэшируются на сессию (mtime+размер), чтобы большие файлы не хэшировались заново при каждом переключении шаблона. |
| Действия с файлами | Повтор, отмена, перестановка ⏫/⏬, удаление файла с диска (с подтверждением), показать в Проводнике Windows. |
| Докачка | Прерванные загрузки сохраняют свой контрольный файл `.aria2`; повторное нажатие на загрузку продолжает, а не начинает заново. |

## Требования

- **ComfyUI** (любая свежая версия с поддержкой кастомных узлов; проверено на ComfyUI 0.3.x + Comfy Desktop 1.x)
- **aria2c** в `PATH` окружения, в котором запускается ComfyUI
- Python-пакет `requests` (уже есть в стандартных установках ComfyUI)
- Поддерживаются Windows / Linux (кнопка «показать в папке» — только Windows; в Linux плагин корректно обходится без неё)

### Установка aria2

- **Windows**: скачайте ZIP с <https://github.com/aria2/aria2/releases> (например, `aria2-1.37.0-win-64bit-build1.zip`), распакуйте и добавьте папку с `aria2c.exe` в ваш пользовательский `PATH`.
- **Linux**: `sudo apt install aria2` / `sudo dnf install aria2` / `brew install aria2` (macOS).
- Проверка: откройте терминал и выполните `aria2c --version`.

## Установка

### Способ 1 — ComfyUI Manager

1. Откройте ComfyUI → **Manager** → **Custom Nodes Manager**.
2. Найдите `ComfyUI-Model-Downloader` и установите.
3. Перезапустите ComfyUI.

### Способ 2 — git clone

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Bosconovitchi/comfyuimodeldownloader.git ComfyUI-Model-Downloader
# restart ComfyUI
```

> **Настольное приложение (Comfy Desktop)**: папка `custom_nodes` находится внутри установки, например `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs\<instance>\ComfyUI\custom_nodes` (путь зависит от раскладки). Если сомневаетесь, посмотрите в логе сервера раздел "Import times for custom nodes", чтобы узнать, какой каталог сканируется на самом деле.

## Использование

1. **Перезапустите ComfyUI** после установки (без перезагрузки сервера у плагина нет интерфейса).
2. Откройте любой **шаблон** (или любой рабочий процесс, узлы которого содержат метаданные `properties.models` — официальные шаблоны их содержат).
3. Подождите ~2 секунды. В **правом нижнем** углу появится плавающая кнопка:
   - `⬇ Download missing models (N)` — отсутствует/повреждено N моделей. **Нажмите её**, чтобы начать загрузку.
4. **Панель менеджера загрузок** откроется автоматически и покажет каждый файл: значок статуса, прогресс-бар, процент, текущую скорость, целевую папку, сообщения об ошибках.
5. Во время загрузки вы можете:
   - Переключать шаблоны → кнопка покажет `Downloading x/y · Pending N (click to enqueue)`. **Автозагрузки нет**; нажмите кнопку, чтобы добавить отсутствующие модели нового шаблона в очередь.
   - В панели: перестановка элементов очереди ⏫/⏬, **Отмена** отдельного элемента, **Остановить всё**, **Повтор** неудачных элементов, **Удалить файл**, **Показать в папке**.
6. Когда всё завершится, панель сохранит итоговые результаты (✅/⚠️), пока вы не закроете её кнопкой ✕.

### Что показывает кнопка

| Ситуация | Текст кнопки | Действие при клике |
|---|---|---|
| Загрузка не идёт, есть отсутствующие модели | `⬇ Download missing models (N)` | Начать загрузку |
| Загрузка идёт, новых отсутствующих нет | `Downloading x/y · file 45%` | Открыть панель |
| Загрузка идёт, у нового шаблона есть отсутствующие модели | `Downloading x/y · Pending N (click to enqueue)` | Добавить их в очередь |
| Всё завершено, часть не удалась | `⚠ x ok / y failed (click to retry)` | Повторить неудачные |
| Ничего не отсутствует | (скрыта) | — |

## Логика загрузки и целостность

Для каждой модели плагин проверяет (по порядку):

1. Файл отсутствует или ≤ 1 МБ → **отсутствует** → скачать.
2. Существует `<file>.aria2` → **незавершён** → aria2c докачает.
3. Размер ≠ записи LFS Hugging Face → **повреждён** → удалить и скачать заново.
4. SHA256 ≠ записи LFS Hugging Face → **повреждён** → удалить и скачать заново (проверяется один раз за сессию для файла, если файл не менялся).
5. После каждой завершённой загрузки SHA256 проверяется заново; несовпадение помечает элемент как неудачный.

Ожидаемые размеры/хэши берутся из `https://hf-mirror.com/api/models/{owner}/{repo}/tree/{rev}?recursive=true` и кэшируются по URL. URL, не относящиеся к Hugging Face (например, Civitai), проверяются только по существованию + `.aria2` + размеру.

## Закрытые репозитории (модели, требующие лицензии)

Некоторые модели (например, LTX-2.5, Gemma) **закрыты** (gated) на Hugging Face — перед загрузкой необходимо принять лицензию / запросить доступ. Плагин это определяет и завершает работу с понятным сообщением вместо загадочной ошибки.

1. Откройте страницу модели на huggingface.co (например, https://huggingface.co/Lightricks/LTX-2.5), войдите в аккаунт и примите условия / запросите доступ.
2. Создайте токен доступа только для чтения: https://huggingface.co/settings/tokens → New token → тип **Read**.
3. Задайте его как переменную окружения для ComfyUI и перезапустите:
   - Windows (PowerShell): `setx HF_TOKEN hf_xxxxxxxx`
   - Linux/macOS: `export HF_TOKEN=hf_xxxxxxxx` (добавьте в скрипт запуска ComfyUI)
4. Перезапустите ComfyUI и повторите попытку — загрузки будут передавать заголовок `Authorization: Bearer <token>`, а метаданные целостности (размер/SHA256) тоже запрашиваются с этим токеном.

## Конфигурация

Все настраиваемые параметры — это константы в начале `__init__.py`:

| Константа | По умолчанию | Значение |
|---|---|---|
| `MAX_CONCURRENT` | `3` | Параллельные файлы |
| флаги aria2 | `-x16 -s16 -k1M` | 16 соединений на файл, фрагменты по 1 МБ |
| `HF_MIRROR` | `https://hf-mirror.com` | Зеркало, используемое для URL `huggingface.co` |
| `MIN_FILE_SIZE` | `1_000_000` | Файлы меньше этого значения считаются отсутствующими |
| `ARIA2_FALLBACKS` | локальные пути | Абсолютные расположения aria2c, пробуемые, если он отсутствует в PATH |

## Устранение неполадок

| Симптом | Решение |
|---|---|
| Плавающей кнопки вообще нет | Полностью перезапустите ComfyUI (в настольной версии: трей → выход). Проверьте в логе сервера запись `Import times for custom nodes: … ComfyUI-Model-Downloader`. На странице выполните жёсткое обновление (Ctrl+R). Проверка здоровья: откройте `http://127.0.0.1:8188/comfy_fetch/ping` → должен вернуться `{"ok": true}`. |
| Кнопка ничего не показывает после открытия шаблона | Узлы рабочего процесса должны содержать метаданные `properties.models` (официальные шаблоны содержат). Для самодельных рабочих процессов без метаданных плагину нечего проверять — добавьте модели вручную. |
| Загрузка сразу падает | `aria2c` не найден → установите aria2 и убедитесь, что он есть в PATH, с которым запускается ComfyUI (требуется перезапуск). |
| Очень медленно | Ваша сеть тоже не может дотянуться до `hf-mirror.com`; попробуйте прокси. |
| Счётчик устарел после переключения шаблона | Подождите ~2 с цикла опроса; если не помогло — жёсткое обновление (Ctrl+R). |
| Действие в панели ничего не делает | Файл может быть уже удалён или его нет в очереди (для перестановки); проверьте значки статуса в панели. |

## Справочник по API (для разработчиков)

Все эндпоинты обслуживает сам сервер ComfyUI (без отдельного порта):

```
GET  /comfy_fetch/ping                       → {"ok": true}
GET  /comfy_fetch/status                     → {"running", "items", "queue"}
POST /comfy_fetch/check   {models:[...]}     → {"missing":[{url,name,directory,reason}]}
POST /comfy_fetch/download {models:[...]}    → {"started":true,"count":N}  (idempotent-ish, dedupes)
POST /comfy_fetch/retry  {name,directory}    → re-queue a failed/cancelled item
POST /comfy_fetch/cancel {name,directory}    → cancel one item (kills its aria2c)
POST /comfy_fetch/stop   {}                  → stop everything
POST /comfy_fetch/reorder {name,directory,direction:"up"|"down"}
POST /comfy_fetch/delete {name,directory}    → delete the model file from disk
POST /comfy_fetch/reveal {name,directory}    → open Explorer at the file (Windows)
```

`reason` для отсутствующих элементов: `missing` | `incomplete` (автодокачка) | `size` | `hash`.
